# dumdumdaw

A modern digital audio workstation (DAW) that doesn't get in your way of making music.

## Motivation

Many music creation tools are expensive, difficult to use, outdated or has a combination for these flaws. This creates barriers for music creators. DumDumDaw project aims to change that by making music creation accessible, simple and enjoyable for everyone.

## Usage

> you have to have uv installed

1) git clone the repo: `git clone https://github.com/bignas-dev/dumdumdaw.git`
2) cd into the directory `cd dumdumdaw`
3) run the app via
```console
uv sync && uv run src/main.py
```
or 
```console
make
```

## Project Stack

- Frontend: Vanilla JS
- Backend: FastAPI (Python)
- Database: SQLite
- Caddy - Reverse proxy
- Docker - Deployment
- Pydub (Python) - music processing library
